SUBIR ARQUIVO DE PROJETO PELO CHAT — COMO INSTALAR
==================================================

Depois disso, você vai poder pedir ao Claude coisas como:

  "sobe o arquivo ~/Downloads/ata-kickoff.docx na pasta de execução
   do projeto Cobrança Automática"

E ele coloca no OneDrive, na pasta certa, sem você abrir o navegador.

São 3 passos e leva uns 10 minutos na primeira vez.


ANTES DE COMEÇAR
----------------

Você precisa de:

  1. Node.js versão 22 ou maior
     Baixe em https://nodejs.org (pegue a opção "LTS").
     Para conferir se já tem, abra o Terminal e digite:  node -v

  2. O repositório og-pulse no seu computador
     Se ainda não tem, peça ao time de tecnologia.

  3. Sua senha do Pulse
     Se você entra só pelo botão da Microsoft e nunca criou senha,
     avise antes — precisamos resolver isso primeiro.


PASSO 1 — RODAR O INSTALADOR
----------------------------

Abra o Terminal, vá até a pasta do projeto e rode:

  bash apps/mcp-drive/install.sh

Ele vai:
  - conferir se o Node está ok
  - compilar o programa
  - perguntar seu e-mail e sua senha do Pulse
  - configurar o Claude sozinho

A senha não aparece na tela enquanto você digita, e não fica gravada
no histórico do Terminal. Isso é de propósito.

Se aparecer "Registrado no Claude Desktop", feche e abra o Claude
Desktop de novo para ele enxergar a novidade.


PASSO 2 — AUTORIZAR SUA CONTA MICROSOFT
---------------------------------------

No Claude, escreva:

  faz login na Microsoft

Ele vai te devolver um endereço de site e um código. Abra o endereço,
digite o código e entre com sua conta da Origami.

Isso é feito uma vez só. Depois disso o acesso se renova sozinho.

IMPORTANTE: o Claude vai enxergar exatamente as pastas que VOCÊ já
enxerga no OneDrive — nem mais, nem menos. Se uma pasta não foi
compartilhada com você, ele também não acessa.


PASSO 3 — TESTAR
----------------

No Claude, peça na ordem:

  1. "qual conta está autorizada no og-pulse-drive?"
     → deve mostrar seu e-mail da Microsoft e do Pulse

  2. "acha o projeto Cobrança"
     → deve listar o projeto e a pasta dele

  3. "lista o que tem na pasta de execução desse projeto"
     → deve mostrar as pastas e arquivos

  4. "sobe o <arquivo> na pasta de execução"
     → faça o primeiro teste com um arquivo qualquer,
       de preferência numa pasta de teste

Deu certo nos quatro? Está funcionando.


O QUE FAZER SE DER ERRADO
-------------------------

"Conta Microsoft não autorizada"
  → refaça o Passo 2.

"Projeto ainda não tem pasta do OneDrive vinculada"
  → alguém precisa escolher a pasta do projeto no Pulse,
    na aba Arquivos. Normalmente é o gerente do projeto.

"Você não tem acesso a esta pasta"
  → não é erro do sistema. Você realmente não tem acesso
    a essa pasta no OneDrive. Peça ao gerente do projeto.

"node: command not found"
  → o Node.js não está instalado. Volte ao item 1.

Qualquer outra coisa: mande print da mensagem para o time de tecnologia.


COISAS QUE VALE SABER
---------------------

- O que você subir aparece para todo mundo que tem acesso à pasta,
  inclusive quem nunca abriu o Pulse. É o OneDrive de verdade.

- Não existe desfazer. Confira o destino antes de confirmar.

- Limite de 100MB por arquivo. Acima disso, use o OneDrive direto.

- A estrutura padrão dos projetos é:
    1.Propostas  — propostas comerciais
    2.Contratos  — contrato assinado e aditivos
    3.Execução   — atas, entregas, material do dia a dia

  Se você não disser a pasta, o Claude vai sugerir uma pela cara do
  arquivo e pedir sua confirmação.
